Detailed Description

template<class Particle_T>
class autopas::VerletListHelpers< Particle_T >::CRSNeighborListPolicy

Policy for managing neighbor lists using the Compressed-Row-Storage (CRS) format.

The neighbor lists are "temporary" neighbor lists that get compressed to CRS neighbor lists afterward. This policy is required by the InteractionListGeneratorFunctor.
