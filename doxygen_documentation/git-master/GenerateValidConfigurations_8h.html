Generates an arbitrary valid configuration constrained to the provided arguments.

Where nullopt is given, no constraints are applied.

Parameters
interactionTypeIf provided, restrict to this interaction type, otherwise consider all interaction types.
containerOptionIf provided, restrict to this container, otherwise consider all options.
traversalOptionIf provided, restrict to this traversal, otherwise consider all options.
loadEstimatorOptionIf provided, restrict to this load estimator, otherwise consider all options.
dataLayoutOptionIf provided, restrict to this data layout, otherwise consider all options.
newton3OptionIf provided, restrict to this Newton 3 option, otherwise consider all options.
cellSizeFactorIf provided, restrict to this cell size factor, otherwise consider {0.5, 1.0, 1.5}.
vectorPatternIf provided, restrict to this vectorization pattern, otherwise consider all options.
throwIfNoneIf true (default), throw when no valid configuration exists; if false, return std::nullopt instead.
Returns
An arbitrary valid configuration matching the given constraints, or std::nullopt if none exists.
