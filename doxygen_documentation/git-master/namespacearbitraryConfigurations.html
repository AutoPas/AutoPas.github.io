Detailed Description

Arbitrary configurations for use in tests where the actual configuration does not matter, but where we need X unique configurations.

We distinguish still between pairwise and triwise configurations.

Note
The concrete option values of every configuration below are ARBITRARY. Tests using them should not assume that the configuration will not change, other than whether it is pairwise or triwise.
