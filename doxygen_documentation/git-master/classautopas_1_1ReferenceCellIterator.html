Detailed Description

template<class Particle_T, bool modifiable>
class autopas::ReferenceCellIterator< Particle_T, modifiable >

Iterator for "references"-based cells, i.e.

where the cell itself does not contain the particles, but all particles are instead stored in a global std::vector, and a cell simply containers the indices of its particles. It provides the same interface as CellIterator.

Note
The iterator stores the address of the particle vector's buffer, so adding particles to that vector while iterating invalidates the iterator (this typically holds for all containers).
Template Parameters
Particle_TType of the particles.
modifiableIf false, this is a const iterator, meaning, the underlying particle can not be modified.
