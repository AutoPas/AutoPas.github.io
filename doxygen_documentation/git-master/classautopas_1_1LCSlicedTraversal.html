Detailed Description

template<class ParticleCell_T, class Functor_T>
class autopas::LCSlicedTraversal< ParticleCell_T, Functor_T >

This class provides the (locked) sliced traversal.

The traversal finds the longest dimension of the simulation domain and cuts the domain into multiple slices along this dimension. Slices are assigned to the threads in a round robin fashion. Each thread locks the cells on the boundary wall to the previous slice with one lock. This lock is lifted as soon the boundary wall is fully processed.

Template Parameters
ParticleCell_Tthe type of cells
Functor_TThe functor that defines the interaction of two or three particles.

Set the SoA sorting-threshold for traversals that use the CellFunctor.

If the sum of the SoA buffer sizes of two cells exceeds this value, the SoA path uses SoAFunctorPairSorted. Traversals that hold a CellFunctor should forward to it; others should explicitly override with an empty body.
